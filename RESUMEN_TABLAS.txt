TABLA CRÍTICA 4: pay_shift (ACUMULACIÓN DE DINERO ACTUAL)
================================================================================

UBICACIÓN: Schema.sql línea 163, Migración 019_ranks_economy.sql

ESTRUCTURA:
┌──────────────┬─────────┬──────────────┬─────────────────┬──────────┐
│ discord_id   │ active  │ accrued_sec  │ collected_sec   │ segment_ │
├──────────────┼─────────┼──────────────┼─────────────────┼──────────┤
│ 123456789    │ true    │ 2400         │ 1800            │ 2024-11.│
│ 987654321    │ false   │ 7200         │ 7200            │ NULL     │
└──────────────┴─────────┴──────────────┴─────────────────┴──────────┘

LÓGICA:
  - Oficial inicia turno (active = true, segment_start = NOW())
  - Sistema suma tiempo cada segundo: (NOW() - segment_start)
  - Cuando finaliza: suma accrued_seconds y marca active = false
  - Dinero pendiente = (accrued_seconds - collected_seconds) * hourly / 600

PUNTO CRÍTICO: Este es DONDE SE CALCULA el dinero pendiente del oficial

RPC USADAS:
  hrp_pay_widget(): Calcula dinero pendiente (lectura)
  hrp_pay_start(): Inicia turno (escrita)
  hrp_pay_end(): Finaliza turno (escrita)
  hrp_pay_collect_srv(): COBRA dinero (escrita SENSIBLE)
