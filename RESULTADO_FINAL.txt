8. ¿Cómo se calcula el dinero del oficial?
   Respuesta: Mediante tabla 'pay_shift' y RPC 'hrp_pay_widget':
              pending = (accrued_seconds - collected_seconds) * hourly / 600
              donde:
              - accrued_seconds = tiempo trabajado (consolidado)
              - collected_seconds = tiempo ya pagado
              - hourly = $ por hora in-game
              - 600 = segundos reales en 1 hora in-game
   Archivo: assets/auth.js línea 1382

SEGURIDAD Y NOTAS IMPORTANTES
================================================================================

1. DATOS SENSIBLES:
   - hrp_pay_collect_srv() y hrp_rank_set_srv() requieren SOLO service_role
   - Se ejecutan desde Netlify function después de verificar Discord roles
   - El cliente JavaScript NO puede llamarlos directamente

2. RLS (Row Level Security):
   - Todas las tablas tienen RLS enabled
   - Políticas: SELECT abierto (using: true), UPDATE/DELETE via DEFINER only

3. DEPARTAMENTOS VÁLIDOS:
   hpd (Houston Police Department)
   hcso (Harris County Sheriff's Office)
   ice (Immigration and Customs Enforcement)
   tph (Texas Highway Patrol)
   hfd (Houston Fire Department)
   dot (Department of Transportation)
   ems (Houston EMS)

4. CONVERSIÓN DE MONEDA:
   1 segundo real = hourly / 600 dinero
   2 horas reales (7200s) de rango con hourly=39 = 468 pesos

5. CACHÉ EN CLIENTE:
   - js/app.js cachea ranks cada 5 minutos
   - Evita consultas repetidas
   - Se invalida si hay cambio de rango en manage-shift

6. NO EXISTE "badge" en BD:
   - Las referencias a "badge" en HTML son elementos UI
   - El número de placa (officer_badge) se usa solo en reportes
   - NO se persiste en BD

Netlify function (rank-admin) y se ejecutan con service_role.
