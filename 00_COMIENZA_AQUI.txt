FLUJO ACTUAL DE ASIGNACIÓN DE RANGO
================================================================================

1. INTERFAZ: manages.html (Panel de Alto Mando)
   Usuario selecciona oficial y nuevo rango
   Hace clic en botón de asignación

2. JAVASCRIPT: assets/auth.js línea 1373
   hrpSetUserRank(targetId, targetName, department, rankKey)
   Llama a hrpRankAdmin('set_rank', {...})

3. NETLIFY FUNCTION: netlify/functions/rank-admin.js
   Verifica que usuario tiene rol de Alto Mando en Discord
   Si OK, ejecuta RPC en Supabase

4. SUPABASE RPC: hrp_rank_set_srv()
   SQL en migración 019_ranks_economy.sql línea 420
   Actualiza: rank_members (nuevo rank_key, hourly)
   Valida: rank_key existe en tabla 'ranks'
   Sella dinero: si hay turno activo, suma accrued_seconds
   Registra: INSERT en rank_history (auditoría)

5. RESULT: Official tiene nuevo rango
   pay_shift.rank_key = nuevo rango
   pay_shift.hourly = nuevo sueldo
   rank_history tiene registro del cambio

================================================================================
FLUJO ACTUAL DE CÁLCULO DE DINERO
================================================================================

1. OFICIAL INICIA TURNO:
   assets/auth.js:1395 → hrpPayStart(discordId, username, department)
   RPC hrp_pay_start() actualiza: pay_shift.active = true, segment_start = NOW()

2. SISTEMA ACUMULA TIEMPO:
   Cada segundo que pasa: NOW() - segment_start suma a accrued_seconds
   El servidor (Supabase) mantiene timestamp, no el cliente

3. DASHBOARD MUESTRA DINERO:
   assets/auth.js:1382 → hrpPayWidget(discordId)
   RPC hrp_pay_widget() calcula:
   pending = (accrued_seconds - collected_seconds) * hourly / 600
   
   Ejemplo: Si hourly=39, tiempo acumulado=7200s (2 horas reales)
   pending = (7200 - 0) * 39 / 600 = 468 pesos

4. OFICIAL FINALIZA TURNO:
   assets/auth.js:1430 → hrpPayEnd(discordId)
   RPC hrp_pay_end() actualiza: accrued_seconds += tiempo desde segment_start
   active = false, segment_start = NULL

5. OFICIAL COBRA DINERO:
   assets/auth.js:1436 → hrpPayCollect()
   Netlify verifica rol, ejecuta: hrp_pay_collect_srv()
   RPC actualiza: economy.balance += pending
   RPC inserta: pay_collections (registro del cobro)
   RPC actualiza: pay_shift.collected_seconds = accrued_seconds
